# UK Trade Websites — Astro rebuild

This is the editable static rebuild of the current WordPress/Breakdance export, held in `uktradewebsitesv4`. **Not production until a preview has been built and accepted.** Existing site files at the repository root are not changed.

## Development

From a complete repository checkout:

```bash
cd astro
npm install
npm run dev
npm run build
```

The prebuild script copies the **specific image assets currently used** from the parent repository's `wp-content/uploads` into `astro/public/wp-content/uploads`. It does not need a running WordPress installation, and it does not modify the source assets.

## Cloudflare Pages preview settings

- Repository: `jordangreenwebsite/uktradewebsitesv4`
- Branch: `feat/astro-rebuild`
- Root directory: `astro`
- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist` (relative to root)
- Node.js: 22

**Do not attach the production custom domain or update the existing production build settings until preview QA passes.** Prefer a separate temporary Cloudflare Pages project or preview configuration.

## Editing

- Colours, type, spacing and responsive CSS: `src/styles/global.css`
- Pricing and agency contact links: `src/data/site.ts`
- Trade-specific landing-page details: `src/data/trades.ts`
- Shared layout and SEO: `src/layouts/BaseLayout.astro`
- Page components: `src/components/` and `src/pages/`
- Trade pages: generated by `src/pages/[trade].astro` — add entries to `src/data/trades.ts`.

See repository `DESIGN.md` for exact migration constraints and design tokens. The first-pass implementation is a recreated design system, **not yet a pixel-perfect approved reproduction**.

### Migration checks

- Confirm media assets, price copy and service-specific pages.
- Manually submit one Formspree test and check the thank-you page.
- Confirm rendering and accessibility at desktop and mobile breakpoints.
- Validate sitemap, schema, canonical URLs, 404s and SEO indexing.
- Once accepted, change Cloudflare deployment settings and keep a rollback path.
